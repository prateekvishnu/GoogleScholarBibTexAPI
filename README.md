# 📚 GoogleScholarBibTexAPI

A lightweight Python script to automatically fetch **BibTeX citations** from **Google Scholar** for a list of paper titles.

---

## 🚀 Get Started

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/GoogleScholarBibTexAPI.git
cd GoogleScholarBibTexAPI
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

Alternatively, manually install them:

```bash
pip install requests beautifulsoup4
```

### 3. Add Your Paper Titles

```bash
paper_titles = [
    "Attention is All You Need",
    "Deep Residual Learning for Image Recognition",
    "AutoML: A Survey of the State-of-the-Art"
]
```

### 4. Run the Script

```bash
python main.py
```
